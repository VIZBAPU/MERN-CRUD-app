# Instruction or steps for using the application

##  Start the application
- Open any terminal (VScode recommended)
- Type "cd 'location of the folder/crud-app'"
- Another way directly open folder in the terminal
- Enter command: 'npm install' to install npm and dependencies
- Enter command: 'npm start' or 'npm run d
- Click on the link mentioned/provided.

## Add a user
- As you open the link to add a user. Your browser would have directed to the form to add a user
- Fill the forms and save the user

## View User
- As soon as you click on save, you will be directed to the new page where you can see existing user.
- Click on the button provided on the right side of the user.

## Edit User
- A form will open up where populated data will be shown to edit for the user.
- Once, you update the data click on update to save the modification.

## Delete User
- Open up the same form again and click on the delete button to delete the user.
- Once clicked on the button. a pop up message will apper to confirm the delete.

## Note
- All of the field in the form are mandatory except Address line 2.
- Email should be unique

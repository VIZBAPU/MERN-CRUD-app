# Project checklist

## Step 1: Setup necessary installations
- Create project, initialize and verify version of Node
- Install other required application and dependecies (Mongoose, Express, Pug)
- Create project structure as required
- Create index.js file
  
## Step 2: Database Connection
- Setup Atlas account and create cluster as informed
- Create connection using link from atlas in the main file of the project (in project: index.js)
- Add user schema below connection setup
- Test connection

## Step 3: Frontend
- Under Views folder create Pug templates
- Create frontend designing with the help of w3css
- Include navigation menu
- Create forms for add or edit page and Table for display page

## Step 4: Backend
- Include GET routes
- create backend for CRUD in index.js file with validation error handling

## Step 5: Testing
- Test all CRUD elements with Screenshot
- Create documents after removing node modules
- Zip the folder for submission
